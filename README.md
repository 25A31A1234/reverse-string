# String Reverser

A simple project to reverse a string.

## Features

* Enter a string
* Reverse the string
* Show original string
* Show reversed string

## Technologies

* C++
* HTML
* CSS
* JavaScript

## Project Structure

```text
string-reverser/

    ├── index.html
    ├── style.css
    └── script.js
```
